Agents at Work #1: AI agents are getting passports

Week of October 12–16, 2026 · about a 6-minute read

This week's theme: as companies move agents into production, the conversation is shifting from "can the agent do it?" to "who said the agent was allowed to?" Four security and IT vendors announced agent-governance features this week. First, a real deployment worth stealing from.

Deployment of the week: ShipStation's "Deckhand" IT help desk agent

ShipStation Global built Deckhand, a Slack-based IT help desk agent on Amazon Bedrock AgentCore, and published the results on October 13. Per the AWS post:

  • It launched in April 2026. In its first three months it handled 1,935 messages, started 1,221 agent conversations and opened 409 Jira tickets.
  • It replied to 97.5% of messages. About a third of questions came in after hours, and Deckhand answered 94% of those.
  • Positive feedback rose from 82% in April to 96% in June after the team revised the prompt and knowledge base based on complaints.
  • The team estimates the 812 conversations that didn't become tickets saved roughly 406 hours over three months (assuming about 30 minutes per ticket).

What makes it work: a knowledge base built from Confluence, the intranet, and resolved Slack threads mined with a strict "only count it if the fix is visible" rule, plus ticket creation that needs a button click to confirm.

Source: AWS Machine Learning Blog, Oct 13, 2026

This week in agentic AI

1. ServiceNow announces "AI Passport" for agents (Oct 15). It's a cryptographically signed credential that agents check at runtime to verify what they're authorized to do, with graduated responses up to a kill switch if an agent drifts. NVIDIA is a design and launch partner. ServiceNow says availability is expected in Q4 2026. ServiceNow newsroom

Worth noting from the release: customer LTM says it has deployed 1,500 AI agents, each assigned an employee ID and a manager.

2. Palo Alto Networks adds guardrails for Claude Enterprise and MCP traffic (Oct 15). Prisma AIRS now plugs into Claude Enterprise (Claude Code, Claude.ai, Claude Cowork) through inference hooks. Its AI Gateway inspects MCP traffic in both directions, blocking concealed instructions and redacting sensitive data. Palo Alto Networks blog

3. Descope ships Agentic Identity Hub 3.0 (Oct 15). It adds an approval workflow for new internal agents (each gets a documented purpose, an owner and least-privilege access), MCP gateway integrations, and alternatives to static API keys such as mTLS and SPIFFE. Descope press release

4. Sophos makes AI Defense generally available (October). It finds unsanctioned AI tools and agents across device, network, identity and browser, and applies real-time guardrails. The release says Sophos X-Ops tracked an attacker using AI agents inside a customer network to build and test nearly 80 malware modules. Sophos press release

The pattern (our take): every one of these treats an agent like an employee or a workload identity: it has an owner, a scope and an audit trail. If you're deploying agents at a small company, you can copy that for free: write down what each agent may do, and who's responsible for it.

Tool spotlight: Make

If you want to build a Deckhand-style workflow without writing a backend, a visual automation platform is the usual starting point. Make says it connects 3,000+ native apps (per its own site). A simple first build: new Slack message in #help → search a knowledge doc → draft a reply → post it only after a human clicks approve.

How-to tip: teach your agent when not to answer

The most underrated part of Deckhand is its "stay quiet" logic. Per the AWS post, it:

  1. Skips announcements, social chatter and human-to-human conversations.
  2. In threads, replies only to the original poster.
  3. Goes silent if a human helper already replied.
  4. Ignores messages that start by @mentioning a person.

If your agent lives in a shared channel or inbox, write these rules into its instructions before you write anything else. An agent that jumps into every conversation gets muted fast.
