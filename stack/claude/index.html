When to look elsewhere

Model choice is rarely the bottleneck for a first agent; process design and data access are. If your whole stack is on Microsoft 365 or Google Workspace with built-in assistants already licensed, start there. For regulated data, read the provider's data terms and HIPAA options before anything sensitive is sent. (Our analysis.)

A setup outline

  1. Pick one document workflow with a clear finished state (a filed form, a redlined contract, a completed review).
  2. Write the playbook a human follows today; that text becomes the agent's instructions.
  3. Run the agent in draft-only mode and have a person approve every output for two weeks.
  4. Store agent configuration in version control so each change is reviewable, as ABC Legal does.
  5. Track hours saved per workflow and the rate of human corrections before adding the next agent.
