Where it fits in an agent build

Murf's API pricing is easy to model: characters in, dollars out. At the published $0.01 per 1,000 characters for the agent-oriented model, a million characters of speech costs about $10, which makes it cheap to give an existing chatbot or phone menu a voice. The studio-quality model at three times that rate suits recorded content such as training modules, product explainers and localised ads. A small team can prototype on the $10 credit before spending anything. (Our analysis.)

When to look elsewhere

If you need a complete phone agent with telephony, routing and booking, Murf is a component, not the product; pair it with a voice platform or buy a hosted receptionist. If voice cloning, music, sound effects and dubbing all matter, compare ElevenLabs' bundled credit plans. Ask for documentation of the compliance claims before sending regulated data. (Our analysis.)

Questions to ask before you buy

  • Which voices and languages are available on the real-time model versus the studio model?
  • What concurrency limits apply on pay-as-you-go, and what do higher limits cost?
  • Can I see documentation for the HIPAA and SOC 2 claims?
  • Do studio subscriptions and API credits share a balance?

A setup outline

  1. Pick the model by use: the real-time model for live agents, the studio model for recorded voiceovers.
  2. Write 20 representative scripts that include prices, names and acronyms, and generate them on the free credit.
  3. Have a native speaker review every language you plan to publish in.
  4. Estimate monthly characters (our rule of thumb: a 1,000-word script is about 6,000 characters) and multiply by the per-1,000 rate.
  5. Keep a shared pronunciation list so every pipeline run sounds the same.
