Where it fits in an agent build

Retell suits a builder or agency that wants to own the prompt, the model choice and the integrations rather than rent a finished receptionist. By our arithmetic from the component table, a typical stack (Retell infrastructure, a platform voice, GPT 6.1 Terra and Twilio US) is $0.117 a minute, so 1,000 minutes is about $117 before monthly items. The self-signed BAA is the detail that separates it from most receptionists we track: a clinic can get a signed HIPAA agreement without an enterprise contract. (Our analysis.)

When to look elsewhere

If nobody on the team will write prompts, test calls and maintain the integration, a finished receptionist is cheaper in practice even when its per-minute rate is higher. Per-minute costs also swing with the model you choose: the same page lists LLMs from $0.0016 to $0.384 a minute, so a careless model pick can multiply the bill. (Our analysis.)

Questions to ask before you buy

  • Which LLM gives acceptable latency for our calls at the lowest per-minute cost?
  • Do we need more than the 20 included concurrent calls at peak?
  • Who owns prompt changes and integration fixes after launch?
  • Is our prompt over 4,000 tokens, which Retell bills as extra time?

A setup outline

  1. Pick the job first (after-hours intake, booking, reminders) and write the three or four outcomes a call can end in.
  2. Start from a template such as Receptionist in the dashboard, then rewrite the prompt for your business.
  3. Choose the LLM and voice on cost and latency; price your expected minutes with the component table.
  4. Add tools: Cal.com booking, transfer to a human with warm handoff, and SMS only if you need it ($20/month).
  5. Sign the BAA before any call carries health information, and set data retention per agent.
  6. Run simulation tests, then put one phone number live on overflow and review transcripts daily.
