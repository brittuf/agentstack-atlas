Where it fits in an agent build

Per-execution billing is the detail that matters for agents. An agent loop that calls a model, checks a result and retries might be fifteen steps; on n8n's cloud that is still one execution. Self-hosting suits businesses with client data they do not want leaving their own server, such as clinics and accounting firms (our analysis). Leads.io's lead qualification and Avalara's tax-agent workflow are the kinds of multi-step jobs that fit, though neither source names n8n. (Our analysis.)

When to look elsewhere

Self-hosting means you own updates, backups and uptime. Teams without anyone comfortable on a server should use the cloud plan or a simpler tool. Prices are listed in euros, so budget for currency movement. (Our analysis.)

A setup outline

  1. Decide cloud or self-hosted first, based on where client data is allowed to live.
  2. Build the workflow with fixed test inputs and confirm one clean execution end to end.
  3. Add the AI agent node with a narrow instruction and a strict output format.
  4. Add an error branch that notifies a person instead of failing silently.
  5. Count executions per day in week one and compare against the plan limits.
