Where it fits in an agent build

Gorgias is built for Shopify stores, and its AI Agent can change orders rather than just describe them: cancel before fulfilment, fix an address, swap a size. That is where most small-store tickets come from, so an agent that acts in Shopify can close them without a person. Pricing by tickets suits stores with many part-time helpers, since Gorgias says its plans are never priced per agent. By our arithmetic, Basic on monthly billing is $90 for 300 tickets and 30 AI interactions; every extra AI interaction also uses a ticket, so heavy automation can push you up a plan sooner than the AI line alone suggests. (Our analysis.)

When to look elsewhere

Outside ecommerce, Gorgias is the wrong tool: its AI Agent setup requires a connected Shopify store, which is why we built no trade guides for it. Stores on other platforms should confirm what the agent can do there before buying. Automated interactions count against the ticket allowance too, so watch both meters. (Our analysis.)

Questions to ask before you buy

  • What does an automated interaction cost on our plan once we pass the included allowance?
  • Which AI Agent actions work on BigCommerce, Magento or WooCommerce stores?
  • Do refunds issued by the AI Agent follow our Shopify refund rules exactly?
  • Can we cap automated interactions per month?

A setup outline

  1. Connect the Shopify store and update app permissions so the AI Agent can read orders.
  2. Add store pages, return policy and shipping FAQ as knowledge; start with guidance templates if you have none.
  3. Create skills for the three biggest ticket types, usually order status, returns and cancellations.
  4. Run test conversations, which are not billed, until the skill outputs match your policy.
  5. Add Shopify actions, starting with address edits and cancellations of unfulfilled orders.
  6. Check monthly how many tickets the AI interactions consumed before choosing a bigger plan.
