Where it fits in an agent build

For builders, the Search API is the part to price. At $5 per 1,000 successful requests, and up to five queries per request, giving a research agent live web results costs half a cent a call with no token billing on the search itself. That is a simple way to add fresh sources to an internal research assistant, the job Rogo automates for bank decks and memos. For marketers, Perplexity is a channel: it shows its sources prominently, so being one of the cited pages has visible value. (Our analysis.)

When to look elsewhere

If your agent only needs your own documents, retrieval over your files is cheaper and easier to control than web search. Consumer plans are no substitute for the API when you need automation. And do not treat any single GEO tactic as a guarantee; outside adding real statistics, the research is mixed. (Our analysis.)

Questions to ask before you buy

  • Which rate limits apply at my usage tier?
  • How are Agent API model tokens billed alongside tool calls?
  • Can results be restricted to specific domains, languages or countries?
  • Is there guidance for publishers on how sources are chosen?

A setup outline

  1. Decide which questions genuinely need the live web, and which your own documents already answer.
  2. Prototype with the Search API and log every result URL the agent relies on.
  3. Batch related queries into one request (up to five) to cut the request count.
  4. Require the agent to cite the URLs it used in every answer.
  5. Review a weekly sample for stale or low-quality sources and add domain filters.
